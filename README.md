AI-Powered Workplace Productivity Assistant
Project Overview

The AI-Powered Workplace Productivity Assistant is an intelligent solution designed to improve workplace efficiency by automating repetitive business tasks. The application leverages Artificial Intelligence to help professionals generate emails, summarize meeting notes, plan tasks, conduct research, and interact with an AI assistant through a user-friendly interface.

The project was developed as part of the CAPACITI AI Skills Acceleration Programme to demonstrate practical AI implementation, prompt engineering, workplace productivity enhancement, and responsible AI practices.

Setup Instructions
Prerequisites
Internet connection
Modern web browser
OpenAI API Key (if applicable)
Installation
Clone the repository:
git clone https://github.com/your-username/ai-productivity-assistant.git
Navigate to the project directory:
cd ai-productivity-assistant
Install dependencies:
npm install
Configure environment variables:

Create a .env file and add:

OPENAI_API_KEY=your_api_key_here
Start the application:
npm start
Open the application in your browser:
http://localhost:3000
